# 画面一覧

## 利用者向け

| ID | 画面名 | 概要 | 状態 |
|---|---|---|---|
| U-01 | ログイン画面 | ユーザーがログインする | 実装済み |
| U-02 | ユーザー登録画面 | 新規ユーザーを登録する | 実装済み |
| U-03 | 店舗一覧画面 | 店舗を一覧表示する | 実装済み |
| U-04 | 商品一覧画面 | 店舗の商品を一覧表示し、販売状態を確認してカートに追加する | 実装済み |
| U-05 | 商品詳細画面 | 商品の詳細を確認する | 未実装 |
| U-06 | カート画面 | カートの商品・数量・所属店舗を確認し、注文対象を選択する | 未実装 |
| U-07 | 注文確認画面 | 選択した商品と注文金額を確認する | 未実装 |
| U-08 | 注文履歴画面 | 過去の注文を確認する | 未実装 |
| U-09 | 注文詳細画面 | 注文の詳細を確認する | 未実装 |
| U-10 | 配送先住所一覧画面 | 登録済み配送先住所を一覧表示し、デフォルト住所を確認・設定する | 未実装 |
| U-11 | 配送先住所登録・編集画面 | 受取人氏名、電話番号、郵便番号、住所を登録・編集する | 未実装 |

### U-07 注文確認画面の動作ルール
- 登録済み配送先住所の一覧から、今回の注文に使用する住所を選択する。
- デフォルト住所がある場合は初期選択する。
- 配送先住所が1件もない場合は、住所登録画面へ誘導し、住所登録完了まで注文を確定できない。
- 注文確定時には、選択した住所の受取人氏名、電話番号、郵便番号、住所を注文に保存する。

### U-10 配送先住所一覧画面の動作ルール
- ログイン中のユーザー自身の住所のみ表示する。
- 登録済み住所を選択してデフォルトに設定できる。
- 住所の新規登録・編集・削除を行える。
- デフォルト住所を削除した場合、他の住所があれば別の住所をデフォルトにする。

### U-11 配送先住所登録・編集画面の入力項目
- 受取人氏名
- 連絡先電話番号
- 郵便番号
- 住所

### U-06 カート画面の動作ルール
- 商品は店舗ごとに所属店舗名と店舗状態を表示する。
- 営業中（`OPEN`）の商品は注文対象として選択できる。
- 休業中（`CLOSED`）の商品は「休業中」と表示し、選択不可にする。
- 休業中の商品もカート内に保持し、数量変更・削除は可能とする。
- 選択商品のみを注文確認画面へ渡す。
- 選択商品がない場合、「注文する」ボタンを無効化する。
- 注文金額は選択商品のみで集計する。

## 補足
店舗一覧画面から店舗を選択すると、商品一覧画面へ遷移する。商品一覧画面では、商品が販売中か売り切れかを表示し、販売中の商品をカートに追加できる。
