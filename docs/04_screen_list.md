# 画面一覧

## 利用者向け

| ID | 画面名 | 概要 |
|---|---|---|
| U-01 | ログイン画面 | ユーザーがログインする |
| U-02 | ユーザー登録画面 | 新規ユーザーを登録する |
| U-03 | 店舗一覧画面 | 店舗を検索・一覧表示する |
| U-04 | 商品一覧画面 | 店舗の商品を一覧表示する |
| U-05 | 商品詳細画面 | 商品の詳細を確認する |
| U-06 | カート画面 | カートの商品を確認・変更する |
| U-07 | 注文確認画面 | 注文内容を確認する |
| U-08 | 注文履歴画面 | 過去の注文を確認する |
| U-09 | 注文詳細画面 | 注文の詳細を確認する |

## 店舗スタッフ向け

| ID | 画面名 | 概要 |
|---|---|---|
| A-01 | ダッシュボード | 店舗の状況を確認する |
| A-02 | カテゴリ管理画面 | カテゴリを管理する |
| A-03 | 商品管理画面 | 商品を一覧・検索する |
| A-04 | 商品登録・編集画面 | 商品を登録・編集する |
| A-05 | 注文管理画面 | 注文を確認・処理する |

## 配達員向け

| ID | 画面名 | 概要 |
|---|---|---|
| D-01 | 配達待ち注文画面 | 配達可能な注文を確認する |
| D-02 | 配達中注文画面 | 担当中の注文を確認する |
